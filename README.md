# Hi there, I'm Rainer Alano 👋

**Associate Data Engineer** · SQL · Python · ETL Pipelines

Petroleum engineer turned data engineer. I build reliable data pipelines, analytics-ready models, and automations that turn raw data into decisions.

## 📁 Featured Projects

- **[ga4_dbt_project](https://github.com/rainer-r/ga4_dbt_project)** - Analytics-ready dbt models on GA4 BigQuery export data. Turns raw event and session data into clean, documented, tested fact and dimension marts for user and session analytics.

- **[ad_marketing_analyst_n8n_workflow](https://github.com/rainer-r/ad_marketing_analyst_n8n_workflow)** - End-to-end ad-marketing workflow in n8n. Extracts campaign data from Google Sheets, cleans and transforms it, generates AI-powered summaries, creates formatted reports, and sends weekly performance insights to Slack.

- **[web_ftp_postgres_etl](https://github.com/rainer-r/web_ftp_postgres_etl)** - ETL pipeline combining Python and SSIS. Extracts OFAC sanction list data from the web, stages it on a local FTP server, and loads it into PostgreSQL. OFAC is the US Treasury's Office of Foreign Assets Control, which publishes a list of sanctioned individuals and entities. This pipeline keeps a local copy in PostgreSQL ready for sanctions screening and compliance checks.
